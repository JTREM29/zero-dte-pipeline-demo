# Copilot Sign-in (VS Code)

This repo uses GitHub Copilot in VS Code for day-to-day ops/dev.

## Sign in
1. Install the extension: **GitHub Copilot** (publisher: GitHub).
2. In VS Code, run: GitHub Copilot: Sign In.
3. Complete the browser/device flow.
4. Verify Copilot is active in the Accounts menu (bottom-left) and that suggestions appear.

## Troubleshooting
- If it loops: run GitHub Copilot: Sign Out then sign in again.
- Confirm your GitHub account has an active Copilot entitlement.
- If behind a proxy/VPN, verify it allows GitHub auth endpoints.
- Update VS Code and the Copilot extension to the latest version.
