# REST
## Partners

### Earnings Call Transcripts

**Endpoint:** `GET /benzinga/v1/transcripts`

**Description:**

A comprehensive database of earnings call and conference call transcripts from publicly traded companies, providing full transcripts, metadata, and confidence scores for corporate earnings calls and investor conferences. Each transcript includes speaker identification, timing information, and transcription quality metrics.

Use Cases: Earnings analysis, sentiment analysis, NLP research, investor research, automated note generation.
